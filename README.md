# mini-project-uts-pemdas26
Kelompok 7 — Sistem Pengelolaan Nilai Sekolah 

Mahasiswa 1 (Sena) — Data Siswa & Input 
* Input NIS dan nama siswa.  
* Input nilai tugas, UTS, dan UAS.  
* Validasi nilai 0–100.  
* Menggunakan do-while.  
* Menampilkan data siswa.  

Mahasiswa 2 (Ngesti) — Proses & Perhitungan 
* Menghitung nilai akhir.  
* Menentukan grade.  
* Menentukan status kelulusan.  
* Menggunakan if-else.  
* Menggunakan for untuk pengolahan nilai.  

Mahasiswa 3 (Inga) — Rekap & Pengujian 
* Menampilkan hasil nilai.  
* Menampilkan grade dan status.  
* Menguji nilai batas kelulusan.  
* Membuat minimal 5 skenario pengujian.  
* Mengintegrasikan program.
